# @d-zero/component

ディーゼロのコンポーネントの規定の一部をまとめてチェックするStylelintルールです。

## 動作

**コンポーネントのクラス名がファイル名と一致しているかをチェックします**

- ファイル名と完全一致するクラス名、またはディーゼロのコンポーネント命名規則（`ファイル名__`で始まる）のクラス名を許可します
- 複数セレクタが自動的に許可されます

### 例

```css
/* button.css */

/* ✅ OK: ファイル名と完全一致 */
.button { ... }

/* ✅ OK: ディーゼロのコンポーネント命名規則の子要素 */
.button__text { ... }
.button__icon { ... }

/* ✅ OK: 複数セレクタも自動的に許可 */
.button, .button__text, .button__icon { ... }

/* ❌ NG: 関係のないクラス名 */
.card { ... }

/* ❌ NG: 他のコンポーネントの子要素 */
.card__text { ... }
```

### SCSSファイルでの特別な動作

- `_`で開始されるパーシャルファイル名は`_`を除いて判定されます
- 1つのファイルに1つのコンポーネントのみが定義されているかもチェックします
- `allowMultipleSelectors`オプションで複数セレクタの許可を制御できます

## Options

`object`: `{ "allowMultipleSelectors": boolean }`

SCSSファイル用のオプション（非推奨）。CSSファイルでは自動的に複数セレクタが許可されます。
